# SIMD 并行加速的高斯消去算法

## 📖 项目简介
本项目为并行程序设计课程实验（Lab 2）。旨在基于 ARM AArch64 架构，利用 **NEON 指令集** 对普通高斯消去算法进行单指令多数据流（SIMD）的并行化优化，解决核心消去循环中的计算瓶颈问题。

## 💻 实验环境
* **硬件平台：** 华为鲲鹏 920 处理器 (ARM AArch64 架构)
* **操作系统：** openEuler
* **编译器：** GCC (g++)
* **编译优化选项：** `-O2`
* **任务调度：** PBS 调度系统 (qsub)
